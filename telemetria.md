
# Prototipo de telemetría GPS

## Descripción
Primer prototipo de Nexus Fleet Core para el procesamiento de coordenadas GPS mediante MQTT.

## Funcionalidades
- Recepción de coordenadas GPS.
- Validación de latitud y longitud.
- Identificación de vehículos.
- Almacenamiento de información de telemetría.
